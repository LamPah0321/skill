# 华为杯论文格式规范（官方）

> 来源：《"华为杯"第二十三届中国研究生数学建模竞赛论文格式规范》
> 发布单位：中国研究生数学建模竞赛专家委员会，2026-09-16。
> 本文件是本仓库在"华为杯"类研究生数模竞赛下**唯一权威的论文格式依据**。
> 所有写作、排版、QA、审稿环节的格式判断都以本文件为准；与旧文档冲突时以本文件为准。

## 1. 选题与交卷

- 每队从 A、B、C、D、E、F 题中**任选一题**完成论文，不得跨题混写。
- 如题目要求，计算结果与编程源程序须在规定时间内上传竞赛系统备查。

## 2. 页面结构

- **摘要页**：论文题目、摘要、关键词统一写在论文摘要页上。
- **正文**：摘要页的**下一页**开始论文正文，摘要页与正文之间不得混入其他内容。
- **页码**：从**摘要页**开始编写页码；页码位于每页**页脚中部**，用阿拉伯数字从"1"起连续编号。
- **页眉**：论文**不能有页眉**。
- **匿名要求**：论文中**不能有任何可能显示答题人身份的标志**（姓名、学校、学号、队号、指导教师、致谢中出现的身份信息等一律删除或脱敏）。

## 3. 字体、字号与行距（硬性）

| 内容 | 字体 | 字号 | 对齐 |
|------|------|------|------|
| 论文题目 | 黑体 | 三号 | 居中 |
| 一级标题 | 黑体 | 四号 | 居中 |
| 其他所有汉字 | 宋体 | 小四号 | —— |

- 全文**单倍行距**。
- 西文/数字与汉字混排时，汉字部分仍按上表执行；不要用默认模板的五号/12pt 正文。

## 4. 摘要要求

- 摘要应简明扼要，**必须包含**：
  1. 建模思路；
  2. 主要方法；
  3. 模型；
  4. 结果与结论；
  5. 创新点；
  6. 关键词。
- 摘要篇幅**一般不超过两页**。
- **无需译成英文**（不要额外附英文摘要）。
- 评阅时对摘要和论文正文都会审阅，摘要是第一阅读点。

## 5. 参考文献与正文引用

### 5.1 正文引用

- 在正文引用处用**方括号**标示参考文献编号，如 `[1]`、`[3]` 或 `[1][3]`。
- **引用书籍还必须指出页码**。
- 参考文献按**正文中的引用先后顺序**列出（不是字母序、不是年份序）。
- 引用别人成果或公开资料（包括网上、博客查到的资料）必须按规定在正文引用处和参考文献中明确列出；**引用程序须注明来源**。

### 5.2 参考文献著录格式（照此排版）

- **书籍**：
  `[编号] 作者，书名，出版地：出版社，起止页码，出版年。`
- **期刊杂志论文**：
  `[编号] 作者，论文名，杂志名，卷期号：起止页码，出版年。`
- **网上资源**：
  `[编号] 作者，资源标题，网址，访问时间（年月日）。`

> 说明：仓库内 `reference-manager` 仍可用 BibTeX 管理与查重；但最终导出到论文的参考文献列表必须套用以上三种中文格式，不得直接把英文 BibTeX 样式（如 `Journal, vol. 149, no. 2, pp. ..., 2023.`）原样贴入。

## 6. 落地检查清单（提交前逐项核对）

- [ ] 只写了一道题（A–F 之一）。
- [ ] 第一页是摘要页：题目 + 摘要 + 关键词；下一页才是正文。
- [ ] 页码从摘要页开始、页脚中部、阿拉伯数字连续。
- [ ] 无页眉；全文无任何答题人身份标志。
- [ ] 题目三号黑体居中；一级标题四号黑体居中；其余汉字小四号宋体；单倍行距。
- [ ] 摘要含建模思路、主要方法、模型、结果与结论、创新点、关键词；≤2 页；无英文摘要。
- [ ] 正文引用为方括号编号；引用书籍已标页码；按引用先后顺序列文献。
- [ ] 书籍 / 期刊 / 网络资源三类文献分别符合 5.2 的写法；引用程序已注明来源。

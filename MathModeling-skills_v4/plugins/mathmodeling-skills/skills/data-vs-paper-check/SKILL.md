# Purpose

这次评审中发现的8个硬伤里，大部分是"论文写的数字和代码输出不一致"。
本 skill 自动从论文中提取所有数值，与实验结果文件比对：

# Checks

## 1. 提取论文中的数字
- 从 paper/sections/*.tex 中提取所有数值：
  - 百分比（如"5.7%"、"占32.1%"）
  - 排名（如"Top1"、"第1位"）
  - 得分（如"0.9966"、"0.818"）
  - 计数（如"6539起"、"3236起"）
  - 预测值（如"9640起"、"3661"）
  - 权重（如"0.331"、"0.289"）
  - 边权/相似度（如"0.685"、"0.980"）
- 记录每个数字所在的文件、行号、上下文句子

## 2. 读取实验结果
- 读取 results/Qx/experiments/round1/ 下所有：
  - csv 文件（用 pandas 读取）
  - json 文件（用 json 读取）
- 建立一个"实验数据库"：键=数值，值=来源文件+行列位置

## 3. 比对
- 对论文中的每个数字：
  - 在实验数据库中搜索是否存在该值（允许四舍五入误差：整数±1，小数±0.01）
  - 如果找不到，标记为 **MISMATCH**：
    - 论文写的是X，但csv/json里是Y
  - 如果找到，记录来源位置
- 特别检查：
  - 表格中的数字（论文表格 vs csv表格）
  - 正文中的排名（论文说"第1名"，csv里是不是第1）
  - 权重值（论文说"自杀式权重0.331"，csv里是不是0.331）

## 4. 分类输出
比对结果分为三类：
- **MATCH**：数字一致，记录来源
- **MISMATCH**：数字不一致，必须修复（这是硬伤）
- **NOT_FOUND**：论文中的数字在实验文件中找不到来源
  - 可能是编造的数字
  - 也可能是计算过程值（论文算了中间值但没存到csv）
  - 如果是后者，需要在代码中补存

# Output

生成 `results/data_vs_paper_report.md`，包含：
- MISMATCH 列表（每个含：论文位置/论文数值/实际数值/来源文件）
- NOT_FOUND 列表
- MATCH 统计
- 严重程度分级：
  - BLOCKER：MISMATCH（必须修复）
  - WARNING：NOT_FOUND（需要确认）
  - INFO：MATCH（无需处理）

# Workflow

1. 扫描 paper/sections/*.tex 提取所有数值及上下文
2. 扫描 results/ 下所有 csv/json 建立实验数据库
3. 逐一比对
4. 生成报告
5. 如果有 BLOCKER 项，返回给 paper-polisher / model-code-analyzer 修复
6. 修复后重新比对，直到所有 BLOCKER 清零

# Note

- 比对时要注意：论文中的数字可能经过四舍五入（如csv是0.3309，论文写0.331）
- 允许合理的四舍五入误差，但如果论文写的和csv差很大（如论文写0.331但csv写0.289），必须标记
- 不要把论文中的公式变量名（如$w_j$）当成数字

# Purpose

摘要是评委看的第一页，也是最容易出低级错误的地方。
本 skill 自动检查摘要的三类问题：
1. 残句（特殊字符截断、句子不完整）
2. 数字与正文不一致
3. 结构不完整（缺建模思路/主要方法/模型/结果与结论/创新点/关键词）

# Checks

## 1. 残句检查
- 检查摘要中是否有未转义的特殊字符：`%`、`&`、`_`、`#`、`$`（在文本模式下）
- 如果有裸 `%`，LaTeX 会截断该行，导致摘要不完整
- 检查摘要每句话是否以句号结尾
- 检查摘要是否在某个数字后突然中断（如"（5.7"后面没有"）"）
- 检查摘要总字数是否在合理范围（华为杯摘要通常300-800字）

## 2. 数字一致性检查
- 从摘要中提取所有数字（百分比、排名、得分、预测值等）
- 在正文 sections/ 中搜索每个数字
- 如果摘要中的数字在正文中找不到对应值，标记为不一致
- 常见问题：摘要写了"一级事件占5.7%"但正文算出来是5.73%，需要确认四舍五入是否一致

## 3. 结构检查（按官方格式规范六要素）
依据：《"华为杯"第二十三届中国研究生数学建模竞赛论文格式规范》（专家委员会，2026-09-16），
详见 `skills-docs/contest-paper-format-huaweibei.md`。摘要**必须包含**以下六项，缺一项即不合格：
- **建模思路**：怎么拆解问题、建模路线（1-2句）
- **主要方法**：用了什么方法/模型（2-3句，须出现具体模型名称，不能只写"建立了数学模型"）
- **模型**：核心模型及其关键设定
- **结果与结论**：得到的关键结果（2-3句，含具体数字）与结论（1-2句，回扣原问题）
- **创新点**：本工作相对常规做法的创新之处
- **关键词**：摘要页末尾须有关键词（通常3-5个）

格式硬约束：
- 摘要篇幅**一般不超过两页**（超过即标记）。
- **无需译成英文**：检查是否误附了英文摘要，有则要求删除。
- 摘要独立成页（摘要页），下一页才开始正文。

检查：
- 六个部分是否都有
- 方法段是否提到了具体模型名称
- 结果段是否有具体数字
- 结论段是否回扣了原问题
- 关键词是否存在且数量合理

## 4. 语言检查
- 是否有明显的AI腔（"随着...的快速发展""综上所述"等套话过多）
- 是否有口语化表达
- 是否有拼写错误

# Output

生成 `paper/abstract_check_report.md`，包含：
- 残句/未转义字符列表（含行号）
- 数字一致性比对结果
- 官方六要素结构检查结果（含篇幅/英文摘要检查）
- 语言建议
- 总分（满分10，华为杯摘要应≥9分）

# Workflow

1. 读取 paper/main.tex 中摘要部分（abstract环境）
2. 读取 paper/sections/ 下所有正文
3. 执行残句检查
4. 提取摘要中的数字，在正文中搜索比对
5. 检查官方六要素结构与篇幅/英文摘要
6. 生成报告
7. 如果发现问题，返回给 paper-polisher 修复

# Purpose

摘要是评委看的第一页，也是最容易出低级错误的地方。
本 skill 自动检查摘要的三类问题：
1. 残句（特殊字符截断、句子不完整）
2. 数字与正文不一致
3. 结构不完整（缺问题/方法/结果/结论）

# Checks

## 1. 残句检查
- 检查摘要中是否有未转义的特殊字符：`%`、`&`、`_`、`#`、`$`（在文本模式下）
- 如果有裸 `%`，LaTeX 会截断该行，导致摘要不完整
- 检查摘要每句话是否以句号结尾
- 检查摘要是否在某个数字后突然中断（如"（5.7"后面没有"）"）
- 检查摘要总字数是否在合理范围（华为杯摘要通常300-800字）

## 2. 数字一致性检查
- 从摘要中提取所有数字（百分比、排名、得分、预测值等）
- 在正文 sections/ 中搜索每个数字
- 如果摘要中的数字在正文中找不到对应值，标记为不一致
- 常见问题：摘要写了"一级事件占5.7%"但正文算出来是5.73%，需要确认四舍五入是否一致

## 3. 四段式结构检查
华为杯一等奖摘要通常包含四段：
- **问题段**：研究了什么问题（1-2句）
- **方法段**：用了什么方法/模型（2-3句）
- **结果段**：得到了什么关键结果（2-3句，含具体数字）
- **结论段**：结论是什么（1-2句）

检查：
- 是否四个部分都有
- 方法段是否提到了具体模型名称（不能只写"建立了数学模型"）
- 结果段是否有具体数字（不能只写"结果表明"）
- 结论段是否回扣了原问题

## 4. 语言检查
- 是否有明显的AI腔（"随着...的快速发展""综上所述"等套话过多）
- 是否有口语化表达
- 是否有拼写错误

# Output

生成 `paper/abstract_check_report.md`，包含：
- 残句/未转义字符列表（含行号）
- 数字一致性比对结果
- 四段式结构检查结果
- 语言建议
- 总分（满分10，华为杯摘要应≥9分）

# Workflow

1. 读取 paper/main.tex 中摘要部分（abstract环境）
2. 读取 paper/sections/ 下所有正文
3. 执行残句检查
4. 提取摘要中的数字，在正文中搜索比对
5. 检查四段式结构
6. 生成报告
7. 如果发现问题，返回给 paper-polisher 修复
